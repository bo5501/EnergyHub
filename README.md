# 星际能量枢纽塔 (Interstellar Energy Hub Tower)

Dyson Sphere Program 的后期建筑。一座玻璃棱镜巨构，把**超大容量储能**和**星球间直连输电**做进同一座塔：
在矿星存下戴森球盈余、给夜面供电、把电力从一个星系直接送到另一个星系，都能用它完成。
最大容量 1 PJ、最大功率 50 TW。

## 功能

**储能**
- 内置 20 级能量池：1 级 100 GJ，每级约 ×1.61，满级 **1 PJ**。
- 充放电功率 `min(50 TW, 容量 ÷ 20 秒)`：任何等级大约 20 秒充满，20 级正好 50 TW。

**星球间输电**
- 同一座塔可切换三种模式：**待机 / 发送 / 接收**。
- 接收端在列表里挑一台发送终端，点「连接」即可开始传输，连接由接收方发起。
- 星际传输功率 `min(50 TW, 容量 ÷ 100 秒)`，比电网充放慢 5 倍 —— 想要更快就多建几台并联。
- 一台发送端可以同时供多台接收端，**按需分配**而不是平均分：每台接收端上报自己当前能吃多少
  （池子空余 + 满功率 5 秒 + 本地电网缺口），发送端按权重切分；池子已满的端权重归零直接退出，
  被卡住的份额会重新分给还有空间的端。

**消耗品**
- 同星系传输：每 200 MJ 消耗 1 个**信息矩阵**。
- 跨星系传输：每 200 MJ 消耗 1 个**空间翘曲器 + 1 个引力透镜**。
- **缺料即停机**：需要的那种料一个都没有就完全不传，不会偷偷按半速白送；
  面板会用红字写明缺哪种料。接收端窗口会直接显示发送端卡槽里的存量，方便对账。
- 卡槽里的**三级增产剂 Mk.III** 让星际传输**提速 ×2**，每秒消耗 1 个，只在真的外送能量时才扣。

**卡槽与送料**
- 6 × 14 = 84 格，可放信息矩阵 / 空间翘曲器 / 引力透镜 / 增产剂 / 升级材料。
- 底座前后共 8 个传送带接入口，可以直接用传送带送料。

**能量池升级**
- 1 → 20 级，每级消耗**空蓄电器 + 引力矩阵**，材料随等级阶梯递增（1~4 级 1000+2000，
  17~19 级 3500+12000）。
- 卡槽里的升级材料会被自动吸进进度池累积，**不必一次凑齐**；升级时先扣进度池，不足再从背包补。

**界面**
- 面板显示「当前储量 / 总容量 + 百分比」，以及实时充放功率。
- 发送端列表逐行显示每个接收端的**需求 / 本帧实得**，拿不到电的会标红。
- 塔顶光环特效跟随实际功率：没电或电网没有空闲能量时会停下。

**联机（Nebula）**
- 支持 Nebula 联机，**主机是唯一权威**：能量结算、扣料、升级判定都只在房主那边跑。
- 客户端的切换模式 / 连接 / 断开 / 升级 / 投料都会立刻上报主机，并转发给其它客户端；
  进星球时主动向主机拉一次该星球的快照。
- 池储量、消耗品卡槽、建筑特效、以及本地电网的充放电状态都会同步，客户端的卫星配电站 /
  电力塔不会显示成「没有电」。
- 面板标题旁显示当前角色：`单机` / `联机 · 主机` / `联机 · 客户端`。
- 需要主机和所有客户端都装 `NebulaMultiplayerModApi` ≥ 2.1.0（Thunderstore 依赖会自动装，
  纯单机装着也没有副作用），且本模组版本一致；第三方分支 **Nebulae 不支持**。

**获取方式**
- 科技树**「能量枢纽」科技右下方一格**（卫星配电系统下方）的「星际能量枢纽塔」，研究消耗信息矩阵。
- 配方：能量枢纽 ×5 + 射线接收站 ×5 + 蓄电器 ×100 + 处理器 ×5，组装台 5 秒。
- 建好后接到本地电网上，点击建筑打开面板。
- 尽力兼容创世之书：科技节点挂在「能量枢纽」右下方，找不到锚点时自动降级，不会把建筑锁死。

## 更新日志

### 1.19.3

**联机同步（Nebula）**
- 枢纽状态支持双向同步：主机结算，客户端操作即改即传，进星球自动拉取快照。
- 同步内容覆盖池储量、工作模式、对接关系、等级、**消耗品卡槽存量**和**建筑特效强度**，
  两端看到的界面与特效保持一致。
- 客户端本地电网按主机的充放电状态结算，修掉了「主机显示正常通电、客户端自己看却是没电」
  的问题（卫星配电站、电力塔及覆盖范围内的建筑不再误判缺电）。
- 状态包带协议版本号：两端版本不一致时丢弃对方的包并在日志提示，不会读出错位数据。

**修复**
- 消耗品没有真正限制传输：旧逻辑在每轮分配里对剩余额度重复打折，没料的塔照样接近满速传能。
  现在**缺料即硬停**，有料时下发量严格封顶在「料的数量 × 200 MJ」。
- 面板直接写明缺哪种料（`⚠ 缺信息矩阵·已停机`），状态变化时日志提示一次。
- 修掉联机或槽位 mod 改动物流清单尺寸后触发的越界报错（自动重建索引映射）。
